# Descriptive Analytics Projects
This repository brings together three descriptive analytics projects focused on understanding data through reporting, visualization, and business insights.

## Projects
#### 1. Spotify Daily Transaction Analytics Report
A descriptive analytics report exploring a synthetic Spotify-style subscription and in-app transaction dataset over a 30-day period.

## Key areas covered:
* Transaction type and value analysis
* Weekly transaction volume and value trends
* Average transaction value distribution
* Channel and customer-segment analysis
* Regional demand and revenue concentration
* Payment preferences and transaction success rates
* Subscriber renewal-risk indicators
* Data limitations and possible next steps toward predictive analytics

Important note: The report uses a synthetic illustrative dataset, not Spotify's private or live transaction records.

#### 2. IBM Cognos Analytics — RetailPulse Practicals

A collection of IBM Cognos Analytics reporting exercises using the RetailPulse Sales package and customer data.

Practicals include:

1. First sales list report
2. Grouped sales report with totals
3. Region and date filters
4. Region-by-product crosstab
5. Prompt-based sales report
6. Customer insights dashboard practical
